# data-engineering-bootcamp
[Data Engineering Zoomcamp](https://github.com/DataTalksClub/data-engineering-zoomcamp) is a free 9-week course on building production-ready data pipelines. By Alexey Grigorev

I utilized this zoomcamp to gain a deeper understanding of data engineering concepts by building an end-to-end data pipeline from scratch. Gain hands-on experience with industry-standard tools and best practices.
